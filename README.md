# interest-density-market
a simple system that shows the density of interest of an object/product represented on a visual map

## what it does?
-Enter a product name
- App does real-time search interest data from Google Trends
- Displays a visual world map colored by trend intensity per country(like a heatmap)

## how to run locally
1. Clone the repo
2. type  ''cd backend"'
3. pip install -r requirements.txt
4. python app.py
5. Open frontend/index.html in your browser
